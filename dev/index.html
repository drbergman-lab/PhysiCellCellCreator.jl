max_hexagonal_grid_points

PhysiCellCellCreator.HexagonalDefaults — Type
HexagonalDefaults

Caller-supplied settings for hexagonal grid patches: the cell radius (per cell type or global) and the spacing factor, giving the default spacing = spacing_factor * 2 * cell_radius for patches that omit a spacing element, and the boundary tolerance (as a fraction of the spacing) used when deciding whether a lattice point lies on the boundary of a patch.

PhysiCellCellCreator.createICCellXMLTemplate — Method
createICCellXMLTemplate(folder::AbstractString)

Create folder path_to_folder and create a template XML file for IC cells.

Introduces a new way to initialize cells in a simulation, wholly contained within a Julia package and outside a PhysiCell runtime. It will not work in PhysiCell! This function creates a template XML file for IC cells, showing all the current functionality of this initialization scheme. It uses the cell type "default". Create ICs for more cell types by copying the cell_patches element.

PhysiCellCellCreator.generateICCell — Method
generateICCell(path_to_ic_cell_xml, domain_dict; output=nothing, cell_radius=nothing, spacing_factor=0.95, boundary_tolerance=1e-10)

Generate initial cell positions from the IC cell XML file at path_to_ic_cell_xml.

domain_dict must contain the keys "x_min", "x_max", "y_min", "y_max", "z_min", and "z_max".

Keyword arguments

  • output: if nothing (default), return a DataFrame with columns x, y, z, and type; otherwise, write a CSV file to this path.
  • cell_radius: the radius of the cells being placed, used to compute the default spacing for patches that use a hexagonal grid but do not specify a spacing element. Either a single Real applied to every cell type or a Dict mapping cell type names (the name attribute of cell_patches) to radii. Only required when a hexagonal grid patch omits spacing.
  • spacing_factor: multiplies the cell diameter to get the default spacing, i.e., spacing = spacing_factor * 2 * cell_radius. The default of 0.95 matches the slightly compressed packing used in PhysiCell's sample projects; 1.0 places cells tangent to their neighbors.
  • boundary_tolerance: for hexagonal grids, lattice points within boundary_tolerance * spacing outside the patch boundary are still kept. The default of 1e-10 only absorbs floating-point rounding so that points exactly on the boundary are not dropped; set it to 0 for a strict comparison.

PhysiCellCellCreator.hexagonalGridPoints — Method
hexagonalGridPoints(spacing, half_width, half_height, boundary_tolerance)

Return the (c1, c2) coordinates of a hexagonal lattice with the given spacing covering [-half_width, half_width] x [-half_height, half_height].

The lattice has a point at the origin, rows parallel to the first axis separated by spacing * sqrt(3) / 2, and alternating rows offset by spacing / 2. Points within boundary_tolerance * spacing outside the region are still kept so floating-point rounding does not drop boundary points. An ArgumentError is thrown if the lattice would exceed max_hexagonal_grid_points points, which almost certainly indicates a spacing typo.

PhysiCellCellCreator.parseHexagonalGrid — Method
parseHexagonalGrid(patch, cell_type, hex_defaults)

Return nothing if the patch's placement attribute is not hexagonal; otherwise, return the lattice spacing (distance between neighboring cell centers).

The spacing comes from the patch's spacing element if present, and otherwise from hex_defaults.spacing_factor * 2 * cell_radius. A hexagonal patch cannot have a number element since the patch size and spacing determine how many cells are placed, and a random patch cannot have a spacing element.
